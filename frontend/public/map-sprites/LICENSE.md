# Licence of the map sprite

`ofm.json`, `ofm.png`, `ofm@2x.json` and `ofm@2x.png` are the OpenFreeMap icon sprite, downloaded unchanged from the URL in `manifest.json`. The map loads them on an instance without [self-hosted map files](../../../docs/engineering.md#self-hosted-map-files). OpenFreeMap builds the sprite in [hyperknot/openfreemap-styles](https://github.com/hyperknot/openfreemap-styles) (`sprites/create_sprites.sh`) from the OSM Liberty and OSM Bright icon sets. That repository states the licences below.

## Icons

The [Maki POI icon set](https://github.com/mapbox/maki/blob/master/LICENSE.txt) is licensed under CC0 1.0 Universal.

The right arrow is derived from [Wikipedia](https://commons.wikimedia.org/wiki/File:Arrowright.svg) and is in the public domain.

## Styles the icons come from

The OSM Liberty style ([maputnik/osm-liberty](https://github.com/maputnik/osm-liberty)) is a fork of the OSM Bright GL Style ([openmaptiles/osm-bright-gl-style](https://github.com/openmaptiles/osm-bright-gl-style)), which is derived from [Mapbox Open Styles](https://github.com/mapbox/mapbox-gl-styles). The OSM Bright GL Style's code is released under the [BSD 3-Clause License](https://opensource.org/license/bsd-3-clause) and its design under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Maps derived from the OpenMapTiles schema credit "© OpenMapTiles" with a link to https://openmaptiles.org/; the map's attribution control carries that credit.
